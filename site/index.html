Yacht

A self-hosted PaaS for Kubernetes. Deploy your app to your own server, with real Kubernetes underneath rather than a Docker wrapper. Runs on K3s, so a $5 VPS is enough to start.

Not ready for production. Yacht is under active development. Interfaces, the database schema, and behaviour all still change without notice, there has been no tagged release yet, and none of it has run anywhere long enough to have earned your trust. Run it on something you can afford to lose, and keep backups you have actually restored from.

Install

curl -sSL https://codeblocktz.github.io/yacht/install.sh | sudo sh

Debian or Ubuntu, amd64 or arm64. Installs K3s, Postgres, and Yacht as a systemd service, then prints your dashboard URL and token.

Upgrade

curl -sSL https://codeblocktz.github.io/yacht/upgrade.sh | sudo sh

Swaps the binary and restarts. Rolls back automatically if the new version does not come up healthy.

Read it first

Piping a script to a root shell deserves a look before you run it: install.sh and upgrade.sh. Both are served here straight from the repository.
